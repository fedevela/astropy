# WCS-004 Architecture Artifact

GUID: `WCS-004`

## Requirement-to-Architecture Map

- `WCS-004` (mixed non-empty/empty tuple inputs must preserve non-empty validation for `wcs_pix2world`)
  - Obligation 1: mixed axis mix where one axis has data and another is empty must keep pre-existing non-empty validation failures.
    - Structural pressure: mixed inputs should remain on validation path unless all axes are empty.
    - Home: `astropy/wcs/wcs.py` → `WCS._array_converter` → `elif len(args) == self.naxis + 1` → `_return_list_of_arrays`.
  - Obligation 2: repeated invalid mixed calls should fail identically per call without switching to empty short-circuit.
    - Structural pressure: no stateful memoization or cross-call mode flag is introduced at the converter boundary.
    - Home: same `WCS._array_converter` path; `WCS._array_converter` executes validation/construction per invocation.
  - Obligation 3: all-empty calls after a prior mixed invalid call should stay in empty no-op path.
    - Structural pressure: explicit transition condition `all_empty` must be evaluated from current call arguments and not influenced by prior failure.
    - Home: `astropy/wcs/wcs.py` → `_return_list_of_arrays` empty-branch condition.

## Placement Decisions

- Primary owning seam: `astropy/wcs/wcs.py` `WCS._array_converter`.
  - Rationale: this method centralizes axis-shape normalization, argument arity dispatch, and conversion branch selection for both `wcs_pix2world` and `all_pix2world`.
- Public API entry seam:
  - `WCS.wcs_pix2world` and `WCS.all_pix2world` continue to delegate to `_array_converter` without extra branching.
- Boundary for WCS-004 behavior:
  - Inside boundary: `len(args) == self.naxis + 1` tuple path and `_return_list_of_arrays` where mixed/empty classification is defined.
  - Outside boundary: low-level transform kernels (`_all_pix2world`, sky normalizers) remain callable only from the non-empty branch.

## Ownership and Boundaries

- Data/flow ownership:
  - `WCS._array_converter` owns:
    - classification of axis inputs by emptiness,
    - selection of empty-output gate,
    - broadcast validation.
  - `WCS` public methods own API contract framing and arity routing only.
  - Traceability files own scenario naming but do not own runtime control-flow.
- Boundary rule:
  - On mixed non-empty/empty input, `np.broadcast_arrays(*axes)` must run and raise shape-related failures under existing error conventions.
  - On all-empty tuple input, `sky == 'output'` branch bypasses transformation and returns empty outputs directly.

## Interface / Contract Artifacts

- `input_container_mode` contract remains the discriminator for container preservation in return shape (`list` vs list-style outputs for list call forms).
- `all_empty`/`has_non_empty` classification contract is implicit in branch logic:
  - `all_empty = all(axis.size == 0 for axis in axes)`
  - `has_non_empty = any(axis.size > 0 for axis in axes)`
  - empty-short-circuit is only valid when `all_empty` is true and `sky == 'output'`.
- Validation contract:
  - `np.broadcast_arrays(*axes)` executes in all non-empty and mixed calls and rethrows with `ValueError("Coordinate arrays are not broadcastable to each other")`.
  - Follow-on shape/dimensional failures remain non-suppressed.

## Dependency Direction

- `WCS.wcs_pix2world`/`WCS.all_pix2world` → `WCS._array_converter`.
- `WCS._array_converter` → `np.broadcast_arrays` for pre-transform validation.
- `_return_list_of_arrays` → `func` (`_all_pix2world`) and sky normalization helpers only when empty-branch guard does not fire.
- Empty-output path is terminal and blocks downstream transform dependencies for deterministic no-op behavior.

## Integration-Seam Skeletons

  - Ensure no pre-emptive state mutation on invalid mixed calls.
- Seam 2: `_return_list_of_arrays`.
  - Maintain current mixed-input classification and only short-circuit when all axes are empty.
  - Preserve non-empty and mixed validation path intact after `broadcast_arrays`.

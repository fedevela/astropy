# WCSXFORM-005 Architecture Map: Preserve malformed non-empty error behavior for `wcs_pix2world` and same-path peers

## Requirement traceability
- `GUID: WCSXFORM-005` — Given malformed or invalid non-empty inputs for `wcs_pix2world` and same-path peer methods, pre-existing exception classes/messages must be preserved and must not be masked by new empty-input handling.
- `GUID: WCSXFORM-005` implementation checkpoints:
  - Verification owner: `astropy/wcs/tests/test_wcs.py`
    - `WCSXFORM_005_VERIFICATION_MAP`
    - `test_wcsxform_005_wcs_pix2world_malformed_non_empty_payload_preserves_legacy_error`
    - `test_wcsxform_005_same_path_peer_world2pix_malformed_non_empty_payload_preserves_legacy_error`
    - `test_wcsxform_005_empty_and_malformed_non_empty_branches_are_disjoint`
  - Implementation owner: `astropy/wcs/wcs.py`
    - `WCS._array_converter()` (shared normalization and branch routing)
    - `WCS._array_converter._return_list_of_arrays()` (mixed-emptiness classification and ValueError continuation path)
    - `WCS.wcs_pix2world()`
    - `WCS.wcs_world2pix()`
    - `WCS.all_pix2world()`
    - `WCS.all_world2pix()`

## Obligation → Architecture pressure map

1. Preserve malformed non-empty `wcs_pix2world` exception contract
- Type pressure: input validation and exception boundary.
- Locus: `WCS._array_converter()` / `WCS._array_converter._return_list_of_arrays()`, then `WCS.wcs_pix2world()`.
- Contract: malformed non-empty payloads must stay on the existing non-empty control path and flow into existing casting/broadcast/wcslib behavior; no added pre-validation branch in `wcs_pix2world()`.

2. Preserve malformed non-empty behavior for same-path peer transforms
- Type pressure: peer-path parity at shared boundary.
- Loci:
  - `WCS.wcs_world2pix()`
  - `WCS.all_pix2world()`
  - `WCS.all_world2pix()`
  - `WCS._array_converter()`
- Contract: all peers continue to delegate malformed inputs through the same `_array_converter` branching and callback seam; no empty-input remapping occurs for non-empty malformed structures.

3. Keep empty-input success disjoint from malformed non-empty failure
- Type pressure: boundary decision rule in shared helper.
- Locus: `WCS._array_converter._return_list_of_arrays()` and `_return_single_array()`.
- Contract:
  - Empty-success branch is only for true all-axis-empty normalized inputs.
  - Partial/mixed emptiness remains on existing mismatch/error route.
  - Existing exception class/message for malformed mixed shapes remains unchanged.

## Placement and ownership

- Primary owner: `astropy/wcs/wcs.py`
  - `WCS._array_converter()` owns input-family normalization and branch discrimination between:
    - fully-empty fast-path and
    - malformed/non-empty or malformed-mixed path.
  - `_return_list_of_arrays()` owns mixed-emptiness invalidity detection and preserves broadcast-origin errors for malformed families.
  - Public methods (`wcs_pix2world`, `wcs_world2pix`, `all_pix2world`, `all_world2pix`) are API boundaries and preserve current callback identity to wcslib kernels.
- Verification owner: `astropy/wcs/tests/test_wcs.py`
  - Holds WCSXFORM-005 requirements in `WCSXFORM_005_VERIFICATION_MAP` and three dedicated placeholder tests.

## Boundary and contract model

- API boundary:
  - `caller -> public WCS method (wcs_pix2world/wcs_world2pix/all_pix2world/all_world2pix) -> WCS._array_converter -> wcslib callback`.
  - No signature changes and no new seams; only behavior discipline at existing shared seam.

- Domain boundary:
  - `_array_converter` remains the sole entry point for axis-family normalizing logic and empty detection.
  - Empty-fast-path can produce zero-length outputs only after all required axes are empty after normalization.
  - Malformed non-empty inputs continue through current validation/type/broadcast path and preserve class/message.

- Error contract boundary:
  - Malformed mixed input family: propagate existing `ValueError`/`TypeError` patterns generated by numpy coercion/broadcasting and wcslib path.
  - Empty contract: produce zero-row/empty-axis outputs via existing return-family rules.

## Dependency direction

- Public methods depend inward on `_array_converter` for all input-family branching.
- `_array_converter` depends inward on NumPy normalization (`np.asarray`, `np.broadcast_arrays`) and wcslib callbacks (`self.wcs.p2s`, `self.wcs.s2p`, `_all_pix2world`, `_all_world2pix` wrappers).
- Tests consume public API only and do not depend on private internals beyond documented behavior in traces.

## Integration seams

- Retain unchanged public seam:
  - `wcs.*` methods -> `_array_converter`.
- Retain unchanged kernel seam:
  - `func` callback arguments to `_array_converter`.
- Do not add new peer-specific conversion seams for malformed input; all peers continue through existing callback route.
